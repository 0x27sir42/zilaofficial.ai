# Project Summary
The ZILA project is a next-generation AI-powered Web3 meme token designed to integrate artificial intelligence with decentralized infrastructure and viral meme culture. It aims to create a community-driven platform that fosters engagement and innovation in the cryptocurrency space, providing users with tools for decentralized governance, tokenomics, and an interactive ecosystem.

# Project Module Description
- **Home**: Features a hero section with a 3D animated ZILA token and a brief introduction to the project.
- **Ecosystem**: Details the AI analytics engine, Web3 infrastructure, meme distribution engine, and community governance.
- **Airdrop**: Allows users to pre-register for the ZILA airdrop with a modal popup for wallet address submission.
- **Tokenomics**: Interactive pie chart visualizing token distribution across various categories.
- **Roadmap**: Outlines the project's phases from concept to future integrations.
- **Partnership**: Displays strategic partnerships with industry leaders.
- **Footer**: Contains company information, security disclaimers, and links to resources.


# File Description Inventory
- **index.html**: The main structure of the website, containing all sections and links.
- **package.json**: Manages project dependencies and scripts for building and running the application.
- **script.js**: Implements interactive features such as navigation, modal handling, and chart rendering.
- **style.css**: Contains styles for the website, including layout, colors, and animations.
- **template_config.json**: Configuration settings for templates used within the project.

# Technology Stack
- **HTML5**: Structure of the web application.
- **CSS3**: Styling and layout management.
- **JavaScript**: Interactivity and dynamic content.
- **Web3**: Integration with decentralized applications.
- **AI Technologies**: For analytics and decision-making functionalities.

# Usage
1. **Install Dependencies**: Run `pnpm install` to install project dependencies.
2. **Build the Project**: Use `pnpm run build` to compile the project.
3. **Run the Project**: Execute `pnpm start` to launch the development server.
